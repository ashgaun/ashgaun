<summary><b>DataLens</b> &nbsp;·&nbsp; natural-language data query agent</summary>

<br/>

Upload any CSV or Excel file and ask questions in plain English. Text-to-SQL over DuckDB, so answers come from real SQL rather than a model reading rows. Exact aggregates over 100,000+ rows in milliseconds, streamed as they compute with an expandable panel showing the plan and generated SQL. Audited the finished build as a sceptical reviewer and found seven defects, each fixed against independently computed ground truth.

`FastAPI` `React` `TypeScript` `DuckDB` `CrewAI`

</details>

Source is private.
